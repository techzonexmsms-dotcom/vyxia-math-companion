# Vyxia Math Companion

https://github.com/aixteampr-cpu/vyxia-math-companion.git
اسحب كود المشروع وكمل عليه، وراجع ملف المواصفات المرفق:
بناء وتجميع منصة Vyxia Math Companion كاملة لطلاب أولى ثانوي بمدارس WE:
- الصفحة الرئيسية ومسار المحادثة (/chat أو /)
- واجهة المحادثة التفاعلية مع الذكاء الاصطناعي بالعامية المصرية وعرض صيغ وتنسيقات المعادلات الرياضية بوضوح
- الشريط الجانبي وسجل المحادثات
- قائمة الدروس والوحدات (الجبر وحساب المثلثات والهندسة التحليلية)
- نظام الاختبارات السريعة (Quiz)
- خيارات اختيار النموذج (Claude Opus 5.5 / GPT-6 Astra / Claude Fable 5.1) عبر بوابة Lovable AI
- دعم رفع المرفقات وتوليد الصور التوضيحية الرياضية
